# Full Stack Task Management Application

A full-stack web application built with **React + Tailwind CSS** on the frontend and **FastAPI + MySQL** on the backend.  
The app supports authentication, user profile display, and CRUD operations on tasks with search and filter functionality.

---

## 🚀 Tech Stack

### Frontend
- React (Create React App)
- Tailwind CSS
- Axios
- React Router

### Backend
- FastAPI
- SQLAlchemy
- MySQL
- JWT Authentication
- Passlib (bcrypt)

---

## ✨ Features

- User Registration & Login (JWT-based authentication)
- Secure Logout
- Display User Profile
- Create, Read, Delete Tasks (MySQL-backed CRUD)
- Search & Filter Tasks
- Clean and responsive UI using Tailwind CSS
